## 集成与状态安全

- [x] 切换成功后，应用客户端、主 Agent、技能执行器和后续子 Agent Provider 同步指向同一目标模型。（验证：切换后读取各组件的公开运行时状态）
- [x] 切换成功后，模型对应的 context window 同步到主 Agent 和状态显示。（验证：为两个模型设置可区分窗口值并观察切换结果）
- [x] 切换不重新创建 Conversation、Session、权限检查器、工具注册表、MCP 管理器、记忆管理器、团队管理器或任务管理器。（验证：切换前后比较对象身份）
- [x] 切换不重复连接 MCP、不重复注册工具、不重复创建团队或任务。（验证：对连接、注册和创建入口设置 spy，切换后调用计数不增加）
- [x] 切换不调用启动 Provider 的完整初始化流程。（验证：对初始化入口设置 spy，运行两次切换后调用计数保持为 0）
- [x] 已经运行的后台子任务继续使用原客户端且不被重启，新建子任务使用切换后的 Provider。（验证：切换前启动一个假后台任务，切换后再启动一个并比较二者模型）
- [x] 后续记忆侧模型请求读取切换后的当前 Provider，但记忆内容和管理器实例不变。（验证：对记忆客户端创建入口设置 spy，并比较管理器身份与内容）
